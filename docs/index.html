SysGuard

System Health Monitor & Auto-Alert Tool. SysGuard watches your CPU, RAM and disk usage live in your terminal, records every reading to a local database, and pops a desktop alert the moment something crosses your thresholds.

How to use

  1. Download Grab the ZIP above and unzip it anywhere you like, e.g. your Desktop.
  2. Double-click run.bat That's it. It sets up everything by itself and starts the monitor. No typing, no setup.
  3. See your system stats Watch CPU, RAM and Disk update live. Close the black window (or press Ctrl+C) when you're done.

Already have Python? Skip the launcher: pip install -r requirements.txt then python monitor.py.

What it does

Live monitoring

CPU, RAM and disk usage refresh every few seconds, with a per-core CPU breakdown.

Smart alerts

Desktop notifications fire once per breach — no spam while a problem is ongoing.

History & reports

Every sample is stored in SQLite; print a daily avg/max summary or export to CSV.

Set & forget

Adjust thresholds in config.yaml, or schedule it to run in the background.
